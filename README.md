# Stopwatch Web Application

## TASK 02

An interactive and user-friendly stopwatch web application for accurately measuring time intervals.

### Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record lap times
- Display total and individual lap times
- Responsive design for mobile and desktop
- Simple and user-friendly interface

### Files

- `index.html` - Website structure
- `style.css` - Design and responsive layout
- `script.js` - Stopwatch and lap functionality
- `README.md` - Project information
